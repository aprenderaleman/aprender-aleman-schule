# Übungsheft C1 — formato de datos (para redactores)

Cada lección del C1 tiene un cuaderno: `server/deutschc1/heft/heft-NN.js`
(NN = id de la lección, dos dígitos). Registro en `server/deutschc1/heft/index.js`.
**El esquema de datos es idéntico al del A1** — lee `docs/deutscha1/HEFT-FORMAT.md`
para los tipos de ítem y la estructura (3 Teile: grammatik → lesen → schreiben).
Aquí solo van las reglas C1.

## Idioma de las instrucciones (C1)

- Alemán culto y natural, du como en todo el curso:
  *Formuliere die Sätze so um, dass die Bedeutung erhalten bleibt.*
- Sin glosas españolas. Toda la gama gramatical disponible.
- Consignas exactas, estilo Prüfungszentrum.

## Diferencias con el A1

- **Teil 1 Grammatik**: 8-10 ítems; dominan luecke (Nominalstil,
  Partizipialattribute, Konnektoren dobles, feste Verbindungen), korrektur
  (matices de registro y colocaciones) y mc; satzbau solo si el orden es el
  punto (máx. 9 palabras); zuordnen para colocaciones Verb-Nomen.
- **Teil 2 Lesen**: texto de 160-220 palabras. Formatos rotando:
  Artikelauszug · Rezension · Essayfragment · Bericht. 4 ítems (mc de 3
  opciones exigentes y rf).
- **Teil 3 Schreiben**: SIEMPRE `variante: 'text'`: `minWoerter: 80`,
  3 `punkte`, tareas tipo examen (Stellungnahme, Textzusammenfassung mit
  Kommentar, formelles Schreiben).

## Calidad

- Resuelve tú cada ítem antes de entregar; claves verificadas.
- Gramática de la lección y anteriores, NUNCA posterior.
- Cero 'Goethe', cero marcas reales. Personajes variados.
- Los ítems reciclan el Kernwortschatz de la lección.
